# 🌿 Sylhet Travel Guide

A modern and interactive travel guide website for exploring the beautiful tourist destinations of **Sylhet, Bangladesh**.

The website provides information about popular tourist spots, including their speciality, best visiting season, approximate distance from Sylhet city, travel time, hotel information, maps, and more.

## 🌐 Live Website

**Live Demo:**
 https://242-115-155.github.io/Sylhet-Travel-Guide/

## ✨ Features

* 🗺️ Explore popular tourist destinations in Sylhet
* 📍 Interactive maps using Leaflet
* 🏨 Hotel information for selected destinations
* 📞 Hotel contact information
* 🌦️ Best season information for each destination
* 🚗 Approximate distance and travel time from Sylhet city
* 🔎 Search and filter tourist destinations
* 🏷️ Destination categories such as:

  * Nature
  * Water
  * Historical
* 🌙 Dark mode / Light mode
* 📌 Save destinations to an itinerary
* 📱 Responsive design for mobile, tablet, and desktop
* ✨ Modern glassmorphism-style UI
* 🖼️ Destination images
* 🎨 Interactive cards and animations
